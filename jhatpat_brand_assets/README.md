# Jhatpat Brand Assets

A starter asset pack based on the approved Jhatpat direction: a rounded, energetic J, warm yellow-to-orange-to-coral gradient, speed trails, and a sparkle.

## Contents

- `svg/jhatpat-symbol.svg` — editable vector symbol on transparent background
- `svg/jhatpat-wordmark-dark.svg` — wordmark for light backgrounds
- `svg/jhatpat-wordmark-light.svg` — wordmark for dark backgrounds
- `png/jhatpat-symbol-1024.png` — transparent symbol, 1024 × 1024
- `png/jhatpat-wordmark-dark.png` / `wordmark-light.png` — transparent wordmarks
- `png/jhatpat-app-icon-dark-1024.png` / `light-1024.png` — square app icons
- `icons/` — app icon PNG sizes and Windows `.ico`

## Palette

- Deep navy: `#081426`
- Ink: `#101B2B`
- Spark yellow: `#FFE72E`
- Amber: `#FFB31A`
- Orange: `#FF7418`
- Coral: `#FF3D32`
- White: `#FFFFFF`

## Usage notes

- Use SVG when possible for scalable branding.
- Use the flat/simplified silhouette as a starting point for tiny 16 × 16 and 32 × 32 icons; inspect at actual size before shipping.
- The wordmark SVG uses a common sans-serif font fallback. For perfectly consistent typography, convert the wordmark text to outlines in a vector editor before final release.
- These are newly authored starter assets inspired by the supplied reference image, not a pixel-perfect extraction of that image.
